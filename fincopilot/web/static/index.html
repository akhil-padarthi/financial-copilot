Financial Copilot

Connecting to the model

Ask a money question. Code does the math.

Llama 3.1 8B reads your question, picks one of 38 calculators and fills in the numbers. The header shows which version is answering. Python computes the answer, and every figure in the reply is checked against that result. Each answer shows its work on the tape below it.

Demo mode: replies to these example questions are recorded, so no model is needed. The calculations are live.
